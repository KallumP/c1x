# Running

To run c1x, open the [launcher](launcher.md) (`c1x_launcher.exe`) and click **Play**.

The game needs the `.nsd`/`.nsf` files from your Crash Bandicoot disc in `streams/`. From the disc itself, copy every file in its `S0` to `S3` folders into `streams/`, renamed to lowercase.

The launcher checks for these files when it opens, and if any are missing it tells you which ones instead of showing **Play**; click **Check again** once they're in place.

If you have a disc image (`.bin` or `.iso`) made from a copy of the game you own, rather than the disc itself, the launcher can extract the files from it for you: in its missing files message, choose the image with **Browse...** (or type its path) and click **Extract**. It says how it went below, and **Play** appears once the files are all there. It needs nothing else installed.

The game boots into the title screen. With a level chosen as the launcher's **Custom level**, its main menu has **CUSTOM LEVEL** under **LOAD GAME**, which starts that level.
